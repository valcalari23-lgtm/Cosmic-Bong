# Código original (2023)

Del código original solo quedan capturas de pantalla.

- `captura-codigo-2023.png`: la lámina "Behinds" del Figma de Valeria, con seis fragmentos del código.
- `codigo-transcrito.md`: la transcripción de esos fragmentos, con una tabla de los datos que se sacan de ahí y la lista de lo que sigue sin saberse.

Claude Code usa esto solo como referencia. No se ejecuta ni se modifica.

Si Valeria encuentra más capturas o los archivos `.pde` completos, van en esta carpeta.
